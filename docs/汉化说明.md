# Equilinox 汉化说明

## 已安装内容

汉化补丁已安装到 Steam 游戏目录：

`C:\Program Files (x86)\Steam\steamapps\common\Equilinox\EquilinoxWindows.jar`

汉化内容包括：

1. **界面文本**：`res/languageSheet.csv` 全部 1174 条文本翻译为简体中文（主菜单、选项、任务、帮助、全部物种名称与描述等）。
2. **中文字体**：重制 `gill3` 与 `segoeUI` 两个位图字体（4096×4096 图集），用微软雅黑补齐了全部 1179 个所需中文字形，保留原版拉丁字形。
3. **硬编码字符串**：修改了 67 个类文件中残留的英文界面文字（如“能力 / 攻击力 / 收获 / 状态 / 捕食”等）。
4. **编码修复**：修改 `MyFile.getReader()` 强制以 UTF-8 读取文本资源，确保中文在任意系统区域下不乱码。
5. **换行修复**：游戏文字引擎只按空格断词，中文没有空格，长文本放不进固定宽度盒子时会崩溃（`ArithmeticException: / by zero`）。已重编译 `TextLoader` / `Line` 两个类，超长文本按字符换行（CJK 标准排版方式），任意文本都不会再崩溃。
6. **字体渲染修复**：字体图集较大且排列紧密，已给字体纹理关闭 mipmap 并启用边缘钳制，避免缩小采样混色。
7. **清除高亮标记杂点**：原版游戏会把文本里的 `^...^` 标记渲染成实心椭圆字形（在文字周围形成同色小点）。已从全部 1174 条翻译中移除这些标记。
8. **文字垂直居中**：全部字形（拉丁 + 中文）整体下移 8 像素，使文字在按钮、选项等界面元素内垂直居中。
9. **修复同色杂点/细线（真正根因）**：字体生成时 `.fnt` 里记录的坐标写成了"墨迹起点"，而游戏解析器把它当作"带内边距的格子左上角"，导致每个字形四边形的采样范围向右/下多伸 10px，正好伸进相邻字形的墨迹里 2px——每个字形边缘都混入相邻字形的一小块，看起来就是"字被截断剩下的边缘"般的同色杂点/细线。已修正为记录格子左上角（与无杂点的旧补丁一致），并同步 xadvance/yoffset 等参数。
10. **修复中文换行出现多余空格**：长中文换行时不再在字符之间插入空格（仅真正的空格会保留字距）。
11. **语言选项显示"汉语"**：语言下拉框中的 English 改为 汉语。
12. **存档名汉化**：已把存档文件重命名为 `Equilinox_0-0-存档_1.dat`，加载世界界面显示"存档 1"（默认存档名也已汉化）。
13. **水域选项**："普通"改为"普通世界"，与世界大小/地形的"普通"区分。
14. **中文字体更换为方正准圆（圆体）**：与游戏原版英文 Gill Sans 的圆润风格更协调（原为微软雅黑）。
15. **抗锯齿优化**：中文字形 16 倍超采样渲染 + 字体纹理 mipmap，消除锯齿且不发虚、不变细（着色器保持原版参数，避免英文发虚）。
16. **底部时间显示格式**：改为"第1年,第1天 - 09:45"。
17. **工具栏 DP 计数器恢复原版布局**：v6 曾把 "+692 dp/分" 合并成单一字符串整体靠左，与英文原版观感不符。已恢复原版双文本结构：数字 "+ N" 固定在组件 5% 处左对齐，单位 "dp/分" 固定在 64% 处左对齐（与英文原版 "dp/min" 位置完全一致），不再替换 `DppmCounter` 类。

## 分享用汉化补丁程序

可直接分享的版本（在 `D:\code\equilinox\发布\` 下）：

- **Equilinox汉化补丁_v6.zip**（约 4MB）：只含改动文件，用系统自带 PowerShell 自动合成汉化 jar。推荐分享。

用法：解压 → 关闭游戏 → 双击「安装汉化.bat」（自动查找游戏目录，也可手动输入）→ 启动游戏。恢复英文原版运行「恢复原版.bat」。安装前自动备份原版为 `EquilinoxWindows.jar.orig.bak`，并把默认存档 `Save_N` 重命名为 `存档_N`。

## 备份与恢复

- 原版 jar 备份：
  - 游戏目录：`EquilinoxWindows.jar.orig.bak`
  - 工作区：`D:\code\equilinox\original\EquilinoxWindows_original.jar`
- 恢复原版：把 `EquilinoxWindows.jar.orig.bak` 改名为 `EquilinoxWindows.jar` 覆盖即可。
- 重新安装汉化：从 `D:\code\equilinox\build\EquilinoxWindows.jar` 复制到游戏目录覆盖。

> 注意：Steam 如果对游戏执行“验证文件完整性”，会把 jar 恢复成原版，重新复制汉化 jar 即可。
